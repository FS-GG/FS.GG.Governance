## Plan Decisions
- PD-001 [AC-001] [FR-001] complete: Add a pure, versioned evidence-boundary evaluator to `FS.GG.Governance.DesignChecks`.  It accepts explicitly classified evidence records and returns deterministic findings for missing semantic, boundary, golden/schema, and production-journey obligations; every accepted record carries provenance class, represented production seam, executed command, exit code, source/head digest, and freshness.
- PD-002 [AC-001] [FR-002] complete: Model dispatch, observed outcome, malformed/unknown input, partial write, and optional degradation as distinct closed cases.  Only `ObservedOutcome` satisfies a native-boundary obligation; malformed or unknown input returns input-state findings and no clean verdict; optional integration is accepted only with the explicit `Degraded` outcome.
- PD-003 [AC-001] [FR-003] complete: Model generated/tool-facing artifacts as records bound to their source, deterministic regeneration result, named consumer, and golden/schema evidence.  A missing consumer, stale regeneration, or missing compatibility proof is a separate named finding rather than an inferred success.
- PD-004 [AC-001] [FR-004] complete: Represent a mitigation as an explicit inventory of all producer classes and a set of mutation results keyed by the producer they reintroduce.  The evaluator rejects a mitigation whose inventory is incomplete or whose mutation does not perturb that producer class.
- PD-005 [AC-001] [FR-005] complete: Add an executable render-evidence fixture that invokes a real local process and persists a stable semantic receipt.  The contract classifies byte reproducibility explicitly; byte-unstable output is only acceptable when the semantic receipt is stable and the classification says so.
- PD-006 [AC-001] [FR-006] complete: Add positive and negative tests over real temporary filesystem/schema/process boundaries, with controls for emission-only, malformed, stale, partial-write, degraded, consumerless, and each producer mutation.  Documentation and the applicable F# governance skill teach the same evidence shapes and point to runnable examples.
